# User Stories for Airbnb Clone Backend

This document translates the use case diagram interactions into user stories that describe how users interact with the system. Each story captures a specific functionality from the user's perspective.

---

## 1. User Registration
As a **new user**, I want to **register an account** so that **I can log in and use the Airbnb platform.**

## 2. User Login
As a **registered user**, I want to **log into my account** so that **I can manage my bookings and listings.**

## 3. Property Listing
As a **host**, I want to **list my property with images, descriptions, and prices** so that **guests can view and book it.**

## 4. Property Search & Booking
As a **guest**, I want to **search for available properties based on date and location** so that **I can book a suitable place to stay.**

## 5. Payment Processing
As a **guest**, I want to **securely pay for my booking** so that **my reservation is confirmed immediately.**

## 6. Booking Management
As a **host**, I want to **view, approve, or decline bookings** so that **I can manage my property's availability.**

## 7. Review System
As a **guest**, I want to **leave reviews for properties I have stayed in** so that **future guests can make informed decisions.**
